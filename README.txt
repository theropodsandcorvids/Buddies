CIVIC CURRICULUM PORTFOLIO
Open index.html after extracting this ZIP, or upload all contents to any static web host.
No build command, database or server-side runtime is required.
All seven PDF downloads use relative docs/ links and travel with the site.
The browser interaction is a prototype, not an LMS or SCORM package.

BEFORE USING FOR A JOB APPLICATION
Replace the candidate-name marker and add the actual resume.
All city results and usability numbers are illustrative source examples.
Replace them with documented candidate work, or retain explicit illustrative labels.
Verify proposed WWC criterion mappings against the current official standard.
Review procurement and privacy language for the relevant jurisdiction.
The website does not collect or submit learner responses.

EDITING
Each of the six HTML pages is self-contained. Edit the relevant text in an HTML editor.
The downloadable PDFs are static sample assets. Update them separately when changing a sample.
PDF filenames use a consistent sample_v1.0 convention. In-document v2.0 references belong to
the supplied teaching scenario, not the actual file release history.
